OpenTyrian2000 한국어판 (개발 중)
================================================================================

Tyrian 2000을 요즘 Windows에서 실행하는 오픈소스 이식판 OpenTyrian2000을
한국어로 옮기는 포크입니다.

게임 안의 글(메뉴, 도움말, 아이템, 브리핑, 데이터 큐브)을 한국어로 옮겼습니다.
아직 실제 플레이로 모든 화면을 확인하지는 못했으니, 어색하거나 넘치는 글이
있으면 알려 주세요.


== 실행 ========================================================================

OpenTyrian2000.exe 를 더블클릭하세요.

게임 데이터(Tyrian 2000 프리웨어)는 data 폴더에 들어 있습니다. data 폴더의
.exe 파일들은 원래 게임(DOS/Windows 95)의 실행 파일이라 쓰지 않습니다.

data 폴더가 없으면 처음 실행할 때 공식 배포처 camanis.net에서
tyrian2000.zip(약 5MB)을 내려받을지 묻습니다. 인터넷을 쓸 수 없다면 아래 주소의
tyrian2000.zip 을 다른 곳에서 받아 이 폴더(OpenTyrian2000.exe 옆)에 두고
실행하세요. 압축은 자동으로 풀립니다.

  https://www.camanis.net/tyrian/tyrian2000.zip


== 요구 사항 ===================================================================

Windows 10(1903 이상) 또는 Windows 11, 64비트


== 조작 ========================================================================

방향키          이동
스페이스        무기 발사
엔터            후방 무기 모드 전환
Ctrl / Alt      왼쪽 / 오른쪽 사이드킥 발사
Alt+Enter       전체 화면 전환

발사 키를 누르고 있는 동안 공격형 특수 무기는 다시 쓸 수 있을 때마다 계속
나갑니다. 진주 바람, 얼음 빔, 바나나 폭탄 같은 발사형과, SDF 주포, 메가 레이저,
플레어처럼 잠깐 이어지는 지속형이 모두 해당합니다. 리펄서와 어트랙터는 누를
때마다 한 번씩 나갑니다. 원래 게임처럼 누를 때마다 한 번씩 쓰려면 설정
메뉴에서 "특수 무기 연사"를 끄세요.

주요 아이템(파워업, 데이터 큐브, 1,000크레딧 이상 보석, 워프 구슬 등)이 걸린
적에는 테두리가 붙습니다. 설정 메뉴의 "아이템 힌트 표시"로 끌 수 있습니다.
아케이드 모드에서 자주 나오는 무기·사이드킥·특수 무기 아이템은 표시하지
않습니다. 다만 레이저와 지카 레이저는 주요 아이템으로 표시합니다(슈퍼 아케이드
제외).

  노랑(깜빡임)  기다렸다 부수면 더 좋은 아이템이 나옵니다. 아직 기다리세요.
  초록          지금 부수면 주요 아이템이 나옵니다(처음부터 싣고 있었거나
                기다린 끝에 실렸거나).
  빨강          부수면 레벨 뒤쪽에서 아이템(워프 구슬 등)이 나옵니다.
  파랑          살려 보내면 레벨 뒤쪽에서 아이템이 나옵니다.
  빨강/파랑 번갈아  부술 때와 살려 보낼 때 나오는 아이템이 서로 다릅니다.

적의 움직임과 레벨 진행을 미리 계산해 표시하므로, 플레이어를 쫓아오는 적이나
여러 적을 차례로 부숴야 하는 경우 등에서는 실제와 다를 수 있습니다.

상점의 전방·후방 무기와 사이드킥 목록에는 가격 오른쪽에 피해량이 나옵니다.

  초당 피해    계속 쏠 때 1초에 주는 피해입니다(보통 게임 속도 기준). 무기는
               지금 위력 단계로 계산하고, 후방 무기는 "7/9"처럼 두 발사 방식을
               함께 보여 줍니다. 충전식 사이드킥은 가장 낮은 단계로 계속 쏠
               때의 값입니다.
  발당 피해    탄약이 제한된 사이드킥의 한 발 피해입니다.

쏜 탄이 모두 적에게 맞는다고 보고 계산한 값이라, 넓게 퍼지는 무기는 실제로 한
적에게 주는 피해가 이보다 적습니다. 발전기 출력이 모자라면 실제로는 더 느리게
쏘게 됩니다.

1인 정식 게임에서 난이도 선택 화면의 "쉬움"을 고르면 아래에 추가 옵션이
나옵니다. 위아래로 고르고 좌우 방향키로 바꾼 뒤 "시작"에서 엔터를 누르세요.

  받는 피해 절반       적의 탄과 충돌로 받는 피해가 절반이 됩니다. 저장한
                       게임을 불러와도 그대로 유지됩니다.
  시작 자금            기본 또는 1,000,000크레딧.
  시작 상점 좋은 장비  첫 상점에 프로토타입 스토커-C, 레이저, 소닉 웨이브
                       (후방), 그래비트론 펄스 웨이브, 마이크로코프 HXS C급,
                       전함급 화염탄(오른쪽 사이드킥)이 추가됩니다.

쉬움으로 시작한 1인 정식 게임은 돈과 장비가 늘어도 난이도가 저절로 오르지
않습니다(다른 난이도는 원래대로 레벨을 마칠 때마다 총자산에 따라 오릅니다).


== 화면 ========================================================================

창 크기는 모니터에 맞춰 자동으로 정해지며(원래 화면 320x200의 정수배),
설정 > 그래픽 메뉴에서 바꿀 수 있습니다.

  화면           창 모드 또는 1번 모니터, 2번 모니터...(그 모니터의 전체 화면)
  창 크기        창 모드의 크기. 자동 또는 1x부터 모니터에 들어가는 최대 배수까지
  확대 방식      픽셀 확대 방식 (None = 각진 픽셀 그대로, Scale2x/hq2x 등 = 윤곽을 다듬음)
  화면 맞춤      정수배 = 정수배로만 확대(가장 선명함)
                 8:5 맞춤 = 화면에 꽉 차게(비율 유지)
                 4:3 맞춤 = 옛 CRT 모니터처럼 세로로 조금 길게

전체 화면은 화면 비율을 유지한 채 남는 부분을 검은 여백으로 둡니다.
윈도우 디스플레이 배율(125%, 150% 등)과 관계없이 모니터의 실제 픽셀로
선명하게 그립니다.

마우스: 게임 플레이 중에는 마우스 포인터가 창 밖으로 나가지 않습니다.
전체 화면에서는 메뉴에서도 포인터가 게임 화면 안에 머뭅니다.


== 파일 위치 ===================================================================

설정과 저장 파일(opentyrian.cfg, tyrian.cfg, tyrian.sav)은 이 폴더에 저장됩니다.
이 폴더에 쓸 수 없는 경우(예: Program Files 아래)에는 아래 위치에 저장됩니다.

  %APPDATA%\OpenTyrian\OpenTyrian2000
