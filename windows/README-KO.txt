OpenTyrian2000 한국어판 (개발 중)
================================================================================

Tyrian 2000을 요즘 Windows에서 실행하는 오픈소스 이식판 OpenTyrian2000을
한국어로 옮기는 포크입니다.

현재 단계: Windows 실행 환경 정비. 게임 안의 텍스트는 아직 영어이며,
한글화는 앞으로 진행합니다.


== 실행 ========================================================================

OpenTyrian2000.exe 를 더블클릭하세요.

처음 실행하면 게임 데이터(Tyrian 2000 프리웨어)를 내려받을지 묻습니다.
[예]를 누르면 공식 배포처 camanis.net에서 tyrian2000.zip(약 5MB)을 받아
data 폴더에 설치한 뒤 게임을 시작합니다.

인터넷을 쓸 수 없다면 아래 주소의 tyrian2000.zip 을 다른 곳에서 받아
이 폴더(OpenTyrian2000.exe 옆)에 두고 실행하세요. 압축은 자동으로 풀립니다.

  https://www.camanis.net/tyrian/tyrian2000.zip


== 요구 사항 ===================================================================

Windows 10(1903 이상) 또는 Windows 11, 64비트


== 조작 ========================================================================

방향키          이동
스페이스        무기 발사
엔터            후방 무기 모드 전환
Ctrl / Alt      왼쪽 / 오른쪽 사이드킥 발사
Alt+Enter       전체 화면 전환


== 화면 ========================================================================

창 크기는 모니터에 맞춰 자동으로 정해지며(원래 화면 320x200의 정수배),
Setup > Graphics 메뉴에서 바꿀 수 있습니다.

  Display        Window(창 모드) 또는 Display 1, 2...(그 모니터의 전체 화면)
  Window Size    창 모드의 크기. Auto 또는 1x부터 모니터에 들어가는 최대 배수까지
  Scaler         픽셀 확대 방식 (None = 각진 픽셀 그대로, Scale2x/hq2x 등 = 윤곽을 다듬음)
  Scaling Mode   Integer = 정수배로만 확대(가장 선명함)
                 Fit 8:5 = 화면에 꽉 차게(비율 유지)
                 Fit 4:3 = 옛 CRT 모니터처럼 세로로 조금 길게

전체 화면은 화면 비율을 유지한 채 남는 부분을 검은 여백으로 둡니다.
윈도우 디스플레이 배율(125%, 150% 등)과 관계없이 모니터의 실제 픽셀로
선명하게 그립니다.

마우스: 게임 플레이 중에는 마우스 포인터가 창 밖으로 나가지 않습니다.
전체 화면에서는 메뉴에서도 포인터가 게임 화면 안에 머뭅니다.


== 파일 위치 ===================================================================

설정과 저장 파일(opentyrian.cfg, tyrian.cfg, tyrian.sav)은 이 폴더에 저장됩니다.
이 폴더에 쓸 수 없는 경우(예: Program Files 아래)에는 아래 위치에 저장됩니다.

  %APPDATA%\OpenTyrian\OpenTyrian2000
